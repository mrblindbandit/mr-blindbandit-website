# Localization and accessibility update

Hosted Filipino and Cebuano editions: home, biography, label overview, contact guide, support guide and press guide (12 pages). Biography covers every supplied source section. Guides are localized adaptations, not full translations of every source-page feature. Navigation, heading structure, language metadata, canonical URLs and reciprocal alternates are localized. Bundled content is editable through the protected translation manager, with explicit review before administrator publication. Archiving suppresses both routing and sitemap inclusion.

Other public pages offer explicitly labeled outbound Google Translate links. These are optional external machine translation, NOT native translated pages, guaranteed translations, or independent SEO pages. The integration never sends portal URLs, query strings, authentication tokens or form values. Google availability varies by region. It does not translate the private portal.

Full native translation of the entire public site and internal portal remains incomplete. Spanish remains available through the pre-existing introduction and reviewed manager.

Accessibility improvements: textarea/tabindex focus rings, forced-colors focus, reduced-motion behavior, localized navigation wrapping, readable headings and keyboard-focusable main content. Target WCAG 2.2 AA; full conformance has NOT been established. Full assistive-technology, keyboard, contrast and workflow testing remains.

Phases 1/2 retain the previously documented independent email/DNS, consent-platform, passkey and advanced SEO gaps. This release does not claim Phase 3/4 completion or add deferred smart links/inventory work.

www DNS/redirect remains unmodified: no connected Cloudflare management service; the existing Sites account has five attached domains.
