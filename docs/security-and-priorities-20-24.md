# Security fixes and priorities 20–24 — 8 September 2026

This release completes ten focused improvements requested by the owner:

1. Recovery-code generation now requests a text-file download, displays all eight codes, provides a repeat download link, copy control and hide control. iPhone may present its preview/share/save interface. Plaintext codes are not persisted server-side. Automatic device download behavior has not been tested on the owner's iPhone.
2. Verified administrators no longer see the OTP-entry form by default on Account & security. Sensitive operations still require a recent verification. The verification component now remains in the account content column instead of being displaced by page rendering.
3. Administrators can inspect their own sessions and revoke an individual other session. Current sessions are labeled. Revocation cannot target another account.
4. Own security activity is visible alongside recovery-code counts and sign-out-all controls. Existing login rate limits, single-use codes and password/session protections remain.
5. Fifteen department email addresses are public at the owner's explicit request. Existing .com sending identity is preserved. Department acknowledgments use the corresponding .net Reply-To address. This release does not modify DNS or independently test those mailboxes.
6. First-party News RSS and Atom endpoints reflect only public, due, indexable articles. Feed discovery links and a feed subscription page are published.
7. First-party Music RSS exposes the existing artist catalog with release titles, dates and established streaming destinations. Smart links remain outside this release, following the owner's earlier exclusion of priority 22.
8. A translation manager supports draft/review/published/archived states, Spanish/Filipino content and metadata, review confirmation, optimistic revisions, language URLs, hreflang and sitemap integration. A concise Spanish introductory homepage is published. It explicitly labels linked English pages; full biography/legal translations are not invented. The browser remembers the chosen language without forcing redirects.
9. Press center has short/medium/long artist-supplied biographies, downloadable text versions and a ZIP containing those biographies, usage guidance and the existing portrait. Press and business contacts are distinguished. No new third-party image rights or logos are claimed.
10. Four dedicated public inquiry forms and four private pipeline pages cover bookings, licensing, sponsorships and partnerships. New submissions enter their department queue. Shared statuses include qualification/proposal/negotiation/won/lost. Existing notes, assignments, follow-up, search, replies, configurable notification destination and sender receipts are reused. Editable reply templates do not automatically promise terms or availability.

Crawl automation continues: newly generated public pages enter the sitemap at deployment; published articles and translations update it dynamically. Draft/future/noindex/private content is excluded. Robots and sitemap remain root Worker responses. Replaced metadata/canonical settings are honored. Protected HTML never ships as static assets.

Validation: portal/community tests cover native login/reset, administrator verification, code reuse, recovery hashing, session ownership, client isolation, inbox lifecycle and translation review/revisions. A database-backed crawl test validates XML, live/draft/future/noindex exclusions, translations, output escaping and empty HEAD responses. Press ZIP and form category routing checked locally. Production email receipt, external mailbox routing and iPhone download UI are not asserted as verified.

Remaining: priority 22 smart links intentionally excluded. Passkeys/TOTP, automated inbound email import, full media-rich CMS, broader translations and other previously listed advanced features remain unfinished. No claim that all priorities 1–24 are complete. The user reports Google setup finished; no certified CMP snippet/configuration was supplied in this request, so existing advertising blocking was not changed and AdSense approval is not claimed.
